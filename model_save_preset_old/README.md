# Архивное хранилище моделей и истории обучения

Эта директория содержит архивные версии моделей нейронных сетей и истории их обучения, которые использовались в ранних этапах проекта по прогнозированию выброса радона для предсказания землетрясений.

## Структура директории

```
model_save_preset_old/
├── models/               # Сохраненные архивные модели в формате .h5
│   ├── group1/           # Архивные модели первой группы
│   ├── group2/           # Архивные модели второй группы
│   └── ...               # Другие группы архивных моделей
├── history/              # История обучения архивных моделей
│   ├── group1/           # История обучения моделей первой группы
│   ├── group2/           # История обучения моделей второй группы
│   └── ...               # История обучения моделей других групп
└── README.md             # Этот файл
```

## Назначение

Эта директория предназначена для хранения устаревших или исторически значимых моделей, которые:
- Использовались на ранних этапах разработки
- Были заменены улучшенными версиями
- Сохранены для сравнительного анализа
- Имеют исследовательскую ценность

## Важное примечание

Данная директория предназначена только для архивных целей. Для текущих рабочих моделей используйте директорию `model_save_preset/`.

## Доступ к архивным моделям

Архивные модели могут быть загружены аналогично актуальным моделям:

```python
import tensorflow as tf

# Загрузка архивной модели
model_path = "model_save_preset_old/models/group1/model_name.h5"
model = tf.keras.models.load_model(model_path)
```

## Анализ архивных моделей

Для анализа и сравнения архивных моделей с текущими можно использовать те же инструменты:
- Визуализатор моделей из директории `visualization/`
- Инструменты оценки из директории `metric_standart/`
