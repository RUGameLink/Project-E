# Хранилище моделей и истории обучения

Эта директория служит централизованным хранилищем для сохраненных моделей нейронных сетей и истории их обучения, которые используются в проекте прогнозирования выброса радона для предсказания землетрясений.

## Структура директории

```
model_save_preset/
├── models/               # Сохраненные модели в формате .h5
│   ├── 1 old/            # Модели группы 1 (старые модели)
│   ├── 2 new/            # Модели группы 2 (новые модели)
│   ├── 3 alt_model/      # Модели группы 3 (альтернативные модели)
│   └── 4 alt_new_model/  # Модели группы 4 (новые альтернативные модели)
├── history/              # История обучения моделей (в формате .pkl или .json)
│   ├── 1 old/            # История обучения моделей группы 1
│   ├── 2 new/            # История обучения моделей группы 2
│   ├── 3 alt_model/      # История обучения моделей группы 3
│   └── 4 alt_new_model/  # История обучения моделей группы 4
└── README.md             # Этот файл
```

## Описание содержимого

### Модели (`models/`)

Хранилище содержит модели нейронных сетей, сохраненные в формате .h5 (Keras/TensorFlow), разделенные на группы по типу архитектуры и поколению разработки:

1. **old** - Базовые модели LSTM/GRU с простой архитектурой
2. **new** - Улучшенные модели с более сложной архитектурой и дополнительными слоями
3. **alt_model** - Альтернативные архитектуры, использующие различные подходы к моделированию
4. **alt_new_model** - Новые версии альтернативных моделей с оптимизированными параметрами

### История обучения (`history/`)

Для каждой модели сохраняется история обучения, содержащая информацию о:
- Значениях функций потерь (loss) на каждой эпохе
- Значениях метрик (accuracy, mae, mse и др.) на каждой эпохе
- Дополнительных параметрах обучения

История хранится в формате:
- `.pkl` - сериализованные Python-объекты (быстрее загружаются)
- `.json` - текстовый формат (более универсальный)

## Использование

### Загрузка моделей

```python
import tensorflow as tf

# Загрузка модели
model_path = "model_save_preset/models/3 alt_model/model_name.h5"
model = tf.keras.models.load_model(model_path)

# Просмотр информации о модели
model.summary()
```

### Загрузка истории обучения

```python
import pickle
import json
import os

# Загрузка истории из .pkl файла
with open("model_save_preset/history/3 alt_model/model_name.pkl", "rb") as f:
    history = pickle.load(f)

# Или из .json файла
with open("model_save_preset/history/3 alt_model/model_name.json", "r") as f:
    history = json.load(f)

# Доступ к метрикам
training_loss = history["loss"]
validation_loss = history["val_loss"]
```

## Инструменты для работы с моделями

- **Визуализация моделей**: используйте инструменты из директории `visualization/` для анализа моделей
- **Инспекция истории**: используйте скрипт `inspect_history.py` в корневой директории для просмотра истории обучения
- **Стандартизированная оценка**: используйте инструменты из директории `metric_standart/` для оценки производительности моделей
