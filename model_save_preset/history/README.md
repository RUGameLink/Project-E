# Хранилище истории обучения моделей

Эта директория содержит сохраненную историю обучения моделей нейронных сетей, используемых для прогнозирования выброса радона с целью предсказания землетрясений.

## Структура директории

```
history/
├── 1 clean model/     # История обучения базовых моделей
├── 2 hybrid model/    # История обучения гибридных моделей
├── 3 experimental model/ # История обучения экспериментальных моделей
├── 4 orcestration model/ # История обучения оркестрированных моделей
└── README.md          # Этот файл
```

## Формат файлов истории

История обучения сохраняется в следующих форматах:
- `.pkl` - сериализованные Python-объекты (бинарный формат)
- `.json` - структурированный текстовый формат

## Содержимое файлов истории

Каждый файл истории обучения содержит следующую информацию:
- Значения функций потерь (loss) на каждой эпохе обучения
- Значения метрик (accuracy, MAE, MSE и др.) на обучающей выборке
- Значения метрик на валидационной выборке
- Дополнительные параметры обучения (например, скорость обучения)

## Использование

Файлы истории могут быть загружены и использованы для:
1. Анализа процесса обучения модели
2. Визуализации изменения метрик по эпохам
3. Сравнения производительности различных моделей
4. Определения оптимального количества эпох обучения

### Пример загрузки и использования истории обучения

```python
import pickle
import json
import matplotlib.pyplot as plt

# Загрузка истории из .pkl файла
with open("model_save_preset/history/2 hybrid model/model_v2.pkl", "rb") as f:
    history = pickle.load(f)

# Альтернативный способ для .json файлов
# with open("model_save_preset/history/2 hybrid model/model_v2.json", "r") as f:
#     history = json.load(f)

# Визуализация изменения функции потерь
plt.figure(figsize=(10, 6))
plt.plot(history["loss"], label="Потери на обучающей выборке")
plt.plot(history["val_loss"], label="Потери на валидационной выборке")
plt.title("Изменение функции потерь в процессе обучения")
plt.xlabel("Эпоха")
plt.ylabel("Значение потерь")
plt.legend()
plt.grid(True)
plt.show()
```

## Анализ и сравнение моделей

Данные из директории истории обучения используются для:
- Выявления проблем переобучения или недообучения
- Сравнения скорости сходимости различных архитектур
- Анализа влияния гиперпараметров на процесс обучения
- Определения наиболее перспективных направлений для дальнейших исследований
