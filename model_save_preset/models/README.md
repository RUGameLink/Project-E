# Хранилище сохраненных моделей нейронных сетей

Эта директория содержит сохраненные модели нейронных сетей в формате `.h5` (Keras/TensorFlow), используемые для прогнозирования выброса радона с целью предсказания землетрясений.

## Структура директории

```
models/
├── 1 clean model/     # Базовые модели с простой архитектурой
├── 2 hybrid model/    # Гибридные модели с улучшенной архитектурой
├── 3 experimental model/ # Экспериментальные модели с нестандартными подходами
├── 4 orcestration model/ # Оркестрированные ансамбли моделей
└── README.md          # Этот файл
```

## Описание групп моделей

### 1. Базовые модели (clean model)

Базовые модели с простой архитектурой, служащие отправной точкой для разработки более сложных решений:
- Простые LSTM/GRU архитектуры
- Минимальная предобработка данных
- Стандартные функции потерь и метрики

### 2. Гибридные модели (hybrid model)

Модели с улучшенной гибридной архитектурой, включающие:
- Комбинации различных типов слоев (LSTM, GRU, сверточные)
- Расширенную предобработку данных
- Оптимизированные гиперпараметры
- Механизмы внимания (attention)

### 3. Экспериментальные модели (experimental model)

Модели с экспериментальными архитектурами:
- Нестандартные подходы к обработке временных рядов
- Продвинутые техники регуляризации
- Мультимодальные входные данные
- Вейвлет-преобразования и другие методы анализа сигналов

### 4. Оркестрированные модели (orcestration model)

Ансамбли моделей и мета-модели:
- Комбинации нескольких моделей разных типов
- Взвешенное усреднение результатов
- Каскадное прогнозирование
- Мета-обучение

## Формат моделей

Все модели сохранены в формате `.h5`, который содержит:
- Архитектуру модели
- Веса модели
- Компилированные параметры (оптимизатор, функция потерь, метрики)

## Использование моделей

```python
import tensorflow as tf

# Загрузка модели
model_path = "model_save_preset/models/2 hybrid model/hybrid_model_v2.h5"
model = tf.keras.models.load_model(model_path)

# Просмотр архитектуры
model.summary()

# Использование для прогнозирования
predictions = model.predict(input_data)
```

## Оценка и сравнение моделей

Для оценки качества моделей используйте инструменты из директории `metric_standart/`, позволяющие выполнить стандартизированную оценку по различным метрикам.

Для визуализации архитектуры и результатов работы моделей используйте инструменты из директории `visualization/`.
