# Тюнингованные модели и традиционные методы машинного обучения

Эта директория содержит модели машинного обучения с тщательно настроенными гиперпараметрами и классические алгоритмы регрессии, используемые для прогнозирования выброса радона с целью предсказания землетрясений.

## Содержимое директории

```
4. tun_model/

├── xgboost_results.json                           # Метрики модели XGBoost
└── README.md                                      # Этот файл
```

## Описание моделей

### Random Forest Regressor
Ансамблевый метод, основанный на построении множества деревьев решений и усреднении их результатов. Настроенная модель случайного леса демонстрирует хорошую производительность на нелинейных данных временного ряда концентрации радона.

### Linear Regression
Базовая модель линейной регрессии, используемая как отправная точка для сравнения. Несмотря на простоту, линейная регрессия обеспечивает интерпретируемые результаты и может быть полезна для определения линейных трендов в данных.

### Support Vector Regression (SVR)
Метод опорных векторов для регрессии, способный моделировать нелинейные зависимости с помощью различных ядер. Настроенная SVR-модель используется для захвата сложных паттернов в данных о концентрации радона.

### XGBoost
Мощный градиентный бустинг деревьев решений, оптимизированный для скорости и производительности. Модель XGBoost с тщательно настроенными гиперпараметрами показывает одни из лучших результатов среди традиционных методов машинного обучения.

## Методология тюнинга

При настройке гиперпараметров моделей использовались следующие методы:
- Поиск по сетке (Grid Search)
- Рандомизированный поиск (Random Search)
- Байесовская оптимизация
- Кросс-валидация с учетом временной структуры данных

## Оценка производительности

Каждая модель оценивалась по нескольким метрикам:
- RMSE (среднеквадратичная ошибка)
- MAE (средняя абсолютная ошибка)
- R² (коэффициент детерминации)
- MSE (средняя квадратичная ошибка)
- MAPE (средняя абсолютная процентная ошибка)

Результаты сохраняются в соответствующих JSON-файлах для каждой модели.
