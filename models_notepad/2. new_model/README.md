# Улучшенные модели второго поколения

Эта директория содержит улучшенные модели нейронных сетей второго поколения для прогнозирования выброса радона с целью предсказания землетрясений. Данные модели представляют собой развитие базовых архитектур с добавлением оптимизированных слоев и улучшенным препроцессингом данных.

## Структура директории

```
2. new_model/
├── 1/              # Первая подгруппа улучшенных моделей
├── 2/              # Вторая подгруппа улучшенных моделей
├── 3/              # Третья подгруппа улучшенных моделей
├── 4/              # Четвертая подгруппа улучшенных моделей
├── 5/              # Пятая подгруппа улучшенных моделей
└── README.md       # Этот файл
```

## Основные улучшения по сравнению с базовыми моделями

1. **Архитектурные улучшения**:
   - Увеличенная глубина сети с дополнительными слоями
   - Оптимизированные размеры скрытых слоев
   - Улучшенная регуляризация (dropout, L1/L2 регуляризация)
   - Механизмы пакетной нормализации (batch normalization)

2. **Предобработка данных**:
   - Расширенный набор признаков
   - Улучшенная нормализация входных данных
   - Более эффективные стратегии обработки пропущенных значений
   - Усовершенствованная временная дискретизация

3. **Обучение**:
   - Адаптивные алгоритмы оптимизации (Adam, RMSprop)
   - Динамическое изменение скорости обучения
   - Ранняя остановка (early stopping) на основе валидационной выборки
   - Callback-функции для сохранения лучших моделей

## Описание подгрупп

### Группа 1
Модели с улучшенной структурой входных данных и расширенным временным окном для учета более долгосрочных закономерностей в данных.

### Группа 2
Модели с комбинацией различных типов рекуррентных ячеек и механизмами внимания для выделения наиболее значимых временных шагов.

### Группа 3
Модели с усовершенствованной регуляризацией и нормализацией для предотвращения переобучения и улучшения обобщающей способности.

### Группа 4
Модели с оптимизированными гиперпараметрами, подобранными с использованием методов автоматического поиска гиперпараметров.

### Группа 5
Экспериментальные модели с нестандартными архитектурными решениями и новыми методами предобработки данных.

## Использование

Каждая подгруппа содержит ноутбуки и/или скрипты с полным циклом обработки данных, обучения и оценки моделей. Для запуска этих моделей следуйте инструкциям в соответствующих ноутбуках.

## Результаты

Модели второго поколения демонстрируют значительное улучшение производительности по сравнению с базовыми моделями, особенно в точности предсказания концентрации радона и в способности обобщать на новые данные.
