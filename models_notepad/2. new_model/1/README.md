# Группа 1: Гибридные модели с улучшенным входным слоем

Эта директория содержит первую группу улучшенных моделей второго поколения, фокусирующихся на оптимизации входного слоя и структуры данных для более точного прогнозирования выброса радона.

## Содержимое директории

```
1/
├── hybrid_model.ipynb           # Notebook с кодом модели и процессом обучения
├── hybrid_model_result.ipynb    # Notebook с результатами и оценкой модели
└── README.md                    # Этот файл
```

## Особенности моделей группы 1

Модели этой группы характеризуются следующими улучшениями:

1. **Оптимизированная предобработка входных данных**:
   - Расширенное временное окно для захвата долгосрочных зависимостей
   - Многомасштабная нормализация для учета различных временных паттернов
   - Комбинирование абсолютных значений и дифференциальных признаков

2. **Архитектурные инновации**:
   - Многоканальный входной слой для обработки данных различных временных масштабов
   - Специализированные модули предобработки для различных типов признаков
   - Адаптивные механизмы взвешивания входных признаков

## Архитектура модели

Гибридная модель этой группы объединяет:
- Предварительную обработку временных рядов с использованием скользящих окон различной длины
- Рекуррентные слои для захвата временных зависимостей
- Плотные слои для интеграции обработанных признаков

```
Вход -> [Многомасштабная предобработка] -> [Рекуррентный блок] -> [Плотный блок] -> Выход
```

## Обучение модели

Процесс обучения модели включает следующие этапы:
1. Загрузка и подготовка данных с использованием расширенного набора признаков
2. Инициализация модели с оптимизированной архитектурой входного слоя
3. Обучение модели с использованием оптимизатора Adam и динамической скорости обучения
4. Валидация модели с использованием отложенной выборки
5. Оценка и визуализация результатов

## Результаты

Результаты обучения и оценки модели представлены в `hybrid_model_result.ipynb`. Ключевые метрики включают:
- RMSE (среднеквадратичная ошибка)
- MAE (средняя абсолютная ошибка)
- R² (коэффициент детерминации)
- Графики сравнения прогнозируемых и фактических значений

## Использование

Для запуска и изучения модели используйте следующие команды:

```bash
# Запуск ноутбука с кодом модели
jupyter notebook models_notepad/2.\ new_model/1/hybrid_model.ipynb

# Просмотр результатов
jupyter notebook models_notepad/2.\ new_model/1/hybrid_model_result.ipynb
```
