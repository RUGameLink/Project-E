# Группа 2: Гибридные модели с комбинированными рекуррентными ячейками

Эта директория содержит вторую группу улучшенных моделей, которые фокусируются на комбинировании различных типов рекуррентных ячеек и механизмов внимания для более эффективного прогнозирования выброса радона.

## Содержимое директории

```
2/
├── hybrid_model_two.ipynb           # Notebook с кодом модели и процессом обучения
├── hybrid_model_two_result.ipynb    # Notebook с результатами и оценкой модели
└── README.md                        # Этот файл
```

## Особенности моделей группы 2

Модели этой группы имеют следующие ключевые особенности:

1. **Комбинирование различных типов рекуррентных ячеек**:
   - Интеграция LSTM и GRU ячеек в единую архитектуру
   - Параллельная обработка временных рядов с использованием разных типов ячеек
   - Объединение выходов различных рекуррентных блоков с помощью взвешенного суммирования

2. **Механизмы внимания**:
   - Внедрение механизмов внимания для выделения наиболее значимых временных шагов
   - Самовнимание (self-attention) для учета взаимосвязей между различными временными точками
   - Вниманиеориентированное объединение выходов разных компонентов модели

## Архитектура модели

Гибридная модель второй группы имеет более сложную структуру:

```
                      ┌─── [LSTM блок] ───┐
                      │                   │
Вход ── [Предобработка] ── [GRU блок] ── [Механизм внимания] ── [Плотный блок] ── Выход
                      │                   │
                      └─── [Bi-RNN блок] ─┘
```

Архитектура включает параллельные ветви с различными типами рекуррентных ячеек, объединенные с помощью механизма внимания, который взвешивает вклад каждой ветви в итоговый прогноз.

## Обучение модели

Процесс обучения включает следующие этапы:
1. Предварительная обработка данных с фокусом на временную структуру
2. Инициализация комбинированной архитектуры с различными типами рекуррентных ячеек
3. Обучение модели с использованием адаптивного оптимизатора и специализированной функции потерь
4. Тонкая настройка весов механизма внимания
5. Анализ вклада различных компонентов в итоговый прогноз

## Результаты

Детальные результаты представлены в `hybrid_model_two_result.ipynb`. Ключевые улучшения по сравнению с моделями первой группы:
- Повышенная точность прогнозирования (сниженные RMSE и MAE)
- Улучшенная способность выделять краткосрочные аномалии в данных
- Более стабильное поведение на долгосрочных прогнозах
- Лучшая интерпретируемость за счет анализа весов механизма внимания
