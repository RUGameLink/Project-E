# Группа 3: Гибридные модели с улучшенной регуляризацией

Эта директория содержит третью группу улучшенных моделей, которые фокусируются на применении продвинутых методов регуляризации для предотвращения переобучения и улучшения обобщающей способности при прогнозировании выброса радона.

## Содержимое директории

```
3/
├── hybrid_model_three.ipynb           # Notebook с кодом модели и реализованными методами регуляризации
├── hybrid_model_three_result.ipynb    # Notebook с результатами и сравнительным анализом
└── README.md                          # Этот файл
```

## Особенности моделей группы 3

Модели этой группы характеризуются следующими особенностями:

1. **Усовершенствованные методы регуляризации**:
   - Комбинирование L1 и L2 регуляризации (Elastic Net)
   - Dropout с оптимизированными параметрами, включая рекуррентный dropout
   - Пакетная нормализация (Batch Normalization) для стабилизации обучения
   - Усеченный обратный градиент (Gradient Clipping) для предотвращения взрыва градиентов

2. **Подходы к борьбе с переобучением**:
   - Расширенная аугментация временных рядов
   - Стохастическая глубина сети (Stochastic Depth)
   - Ранняя остановка (Early Stopping) с оптимизированными критериями
   - Регуляризация по весам ансамбля (Ensemble Weights Regularization)

## Архитектура модели

Архитектура базируется на моделях группы 2, но с добавлением усовершенствованных слоев регуляризации:

```
Вход ── [Предобработка] ── [Регуляризованный LSTM блок] ── [Регуляризованный плотный блок] ── Выход
          │                            │
          └──── [Batch Normalization] ─┘
```

## Особенности реализации

1. **Настройка регуляризации для рекуррентных слоев**:
   - Оптимизированные параметры dropout в LSTM/GRU ячейках
   - Рекуррентный dropout для внутренних состояний ячеек
   - Временная вариативность параметров dropout (Time-varying Dropout)

2. **Регуляризация выходных слоев**:
   - Контроль сложности модели через ограничение норм весов
   - Байесовская регуляризация для оценки неопределенности
   - Специализированные функции потерь с встроенной регуляризацией

## Процесс обучения

Процесс обучения включает:
1. Загрузка и подготовка данных с расширенной аугментацией
2. Инициализация модели с комплексной архитектурой и регуляризацией
3. Обучение с использованием продвинутых техник:
   - Циклическая скорость обучения (Cyclical Learning Rate)
   - Мониторинг и адаптация параметров регуляризации
   - Ранняя остановка на основе валидационной выборки
4. Оценка стабильности модели на тестовой выборке

## Результаты

Ключевые результаты, представленные в `hybrid_model_three_result.ipynb`:
- Улучшенная обобщающая способность на новых данных
- Снижение разрыва между обучающей и тестовой производительностью
- Более стабильные предсказания при значительных изменениях входных данных
- Надежная оценка неопределенности прогнозов

## Преимущества подхода

Модели этой группы особенно хорошо работают в условиях ограниченного объема данных и сложных паттернов во временных рядах концентрации радона. Улучшенная регуляризация позволяет:
- Избежать заучивания случайных флуктуаций в данных
- Повысить надежность прогнозов при долгосрочном предсказании
- Лучше генерализовать модель для работы с данными с новых датчиков
