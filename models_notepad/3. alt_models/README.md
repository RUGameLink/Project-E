# Альтернативные модели нейронных сетей

Эта директория содержит экспериментальные архитектуры нейронных сетей для прогнозирования выброса радона, отличающиеся от стандартных подходов, использованных в других группах моделей.

## Обзор альтернативных моделей

Альтернативные модели включают:
- Архитектуры с использованием сверточных слоев (CNN)
- Модели на основе механизма внимания (Attention)
- Гибридные архитектуры CNN-LSTM/GRU
- Экспериментальные подходы с нестандартной предобработкой данных

## Архитектурные особенности

Альтернативные модели в этой директории характеризуются:
- Использованием нестандартных архитектур нейронных сетей
- Экспериментальными подходами к обработке временных рядов
- Различными комбинациями слоев и функций активации
- Модифицированными функциями потерь

## Результаты экспериментов

Лучшие модели из этой директории экспортируются в центральное хранилище `model_save_preset/models/3 alt_model/` для дальнейшего использования и сравнительного анализа.

## Инструкции по использованию

1. Для обучения новых альтернативных моделей используйте Jupyter ноутбук в корне проекта
2. Сохраняйте новые модели в соответствующую группу
3. Документируйте особенности архитектуры и результаты
4. Лучшие модели копируйте в централизованное хранилище для последующего анализа
