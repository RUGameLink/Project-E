# Гибридные модели нейронных сетей

Эта директория содержит новейшие гибридные модели, объединяющие различные подходы машинного обучения и глубокого обучения для прогнозирования выброса радона с целью предсказания землетрясений.

## Описание гибридных моделей

### CatBoost + XGBoost + 1D-CNN + LSTM
Комплексная гибридная модель, объединяющая:
- Градиентный бустинг CatBoost для обработки категориальных данных
- Градиентный бустинг XGBoost для высокоточного предсказания на числовых данных
- 1D свёрточные слои (CNN) для извлечения локальных паттернов во временном ряде
- LSTM-слои для моделирования долгосрочных зависимостей

### XGBoost + LSTM (третья метамодель)
Гибридная модель, объединяющая:
- XGBoost для точного предсказания на основе статистических паттернов
- LSTM для захвата временных зависимостей и сезонности в данных
- Метамодель, объединяющая результаты двух подходов

### CatBoost + 1D-CNN + Attention
Гибридная модель, комбинирующая:
- CatBoost для моделирования нелинейных зависимостей
- 1D свёрточные нейронные сети для обработки временного ряда
- Механизм внимания (Attention) для выделения наиболее важных временных шагов

### XGBoost + Keras
Гибридный подход, объединяющий:
- XGBoost для высокоточного моделирования нелинейных зависимостей
- Нейронную сеть, реализованную с помощью Keras, для обработки сложных временных паттернов

## Архитектурные особенности

Гибридные модели в этой директории имеют следующие ключевые характеристики:
- Многоуровневая архитектура, объединяющая несколько моделей
- Объединение результатов разных алгоритмов с использованием стекинга или блендинга
- Использование выходов традиционных алгоритмов ML в качестве входных признаков для нейронных сетей
- Механизмы внимания для выделения наиболее информативных частей временного ряда

## Производительность

Гибридные модели демонстрируют наилучшую производительность среди всех разработанных подходов, сочетая преимущества традиционных алгоритмов машинного обучения и глубоких нейронных сетей:
- Улучшенная точность предсказания
- Снижение вероятности переобучения
- Лучшая способность к обобщению на новых данных
- Способность учитывать как краткосрочные, так и долгосрочные зависимости в данных

## Использование

Для запуска и экспериментов с гибридными моделями используйте соответствующие Jupyter ноутбуки или Python-скрипты:

```bash
jupyter notebook models_notepad/5.\ NEW_hibryd_models/CatBoost_+_XGBoost_+_1D_CNN_+_LSTM.ipynb

# Или запуск скрипта
python models_notepad/5.\ NEW_hibryd_models/catboost_+_xgboost_+_1d_cnn_+_lstm.py
```
