# Блокнот моделей нейронных сетей

Эта директория содержит различные группы моделей нейронных сетей, разработанных для прогнозирования выброса радона с целью предсказания землетрясений.

## Структура директории

```
models_notepad/
├── 1. old_models/     # Группа ранних моделей с базовой архитектурой
├── 2. new_model/      # Группа улучшенных моделей второго поколения
├── 3. alt_models/     # Группа альтернативных архитектур моделей
├── 4. tun_model/      # Группа тюнингованных моделей с оптимизированными гиперпараметрами
├── 5. NEW_hibryd_models/ # Группа гибридных моделей, сочетающих различные подходы
└── README.md          # Этот файл
```

## Описание групп моделей

### 1. old_models (старые модели)
Первое поколение моделей с базовой архитектурой LSTM/GRU. Используются как отправная точка и для сравнения с более новыми подходами.

### 2. new_model (новые модели)
Второе поколение моделей с усовершенствованной архитектурой и улучшенным препроцессингом данных.

### 3. alt_models (альтернативные модели)
Экспериментальные архитектуры, включающие варианты с использованием сверточных слоев, моделей внимания и других подходов.

### 4. tun_model (тюнингованные модели)
Модели с оптимизированными гиперпараметрами, прошедшие процесс тонкой настройки с использованием различных методик оптимизации.

### 5. NEW_hibryd_models (новые гибридные модели)
Новейшие гибридные архитектуры, сочетающие различные типы слоев и подходов к моделированию временных рядов.

## Использование

Эта директория предназначена для разработки и тестирования различных архитектур моделей. Лучшие модели экспортируются в каталог `model_save_preset` для дальнейшего использования в проекте.

## Примечания для разработчиков

- При разработке новой модели рекомендуется создать для нее отдельную подпапку в соответствующей группе
- Каждая модель должна содержать документацию по архитектуре и результатам обучения
- Для визуализации и сравнения моделей используйте инструменты из директории `visualization`
- Для стандартизированной оценки метрик моделей используйте инструменты из директории `metric_standart`
