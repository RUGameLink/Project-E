# Базовые модели нейронных сетей

Эта директория содержит первое поколение моделей нейронных сетей, разработанных для прогнозирования выброса радона с целью предсказания землетрясений. Модели используют базовые архитектуры рекуррентных нейронных сетей.

## Содержимое директории

```
1. old_models/
├── test_Bidirectional_model.ipynb  # Модель с двунаправленными слоями
├── test_rnn_model.ipynb            # Базовая RNN модель
├── test_GRU_model.ipynb            # Модель на основе GRU-ячеек
├── test_lstm_model.ipynb           # Модель на основе LSTM-ячеек
├── test_Deep_RNN_model.ipynb       # Глубокая RNN модель
└── README.md                       # Этот файл
```

## Обзор моделей

### Bidirectional Model
Нейронная сеть с двунаправленными слоями, обрабатывающими временной ряд как в прямом, так и в обратном направлении, что позволяет учитывать более полный контекст данных.

### RNN Model
Базовая рекуррентная нейронная сеть, представляющая собой простейшую архитектуру для работы с последовательными данными.

### GRU Model
Модель на основе Gated Recurrent Unit (GRU), которая решает проблему исчезающего градиента и более эффективно обрабатывает долгосрочные зависимости по сравнению с базовой RNN.

### LSTM Model
Модель на основе Long Short-Term Memory (LSTM), способная запоминать значимую информацию на длительных промежутках времени и селективно забывать несущественную.

### Deep RNN Model
Более глубокая версия рекуррентной нейронной сети с несколькими рекуррентными слоями для улучшения способности выявления сложных паттернов во временных рядах.


## Результаты

Модели из данной группы формируют базовую линию производительности, с которой сравниваются более продвинутые архитектуры из других групп. Несмотря на свою простоту, некоторые из этих моделей показывают достаточно хорошие результаты, особенно LSTM и Bidirectional модели.
