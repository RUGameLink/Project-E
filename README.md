# Проект по прогнозированию выброса радона для предсказания землетрясений

Этот проект направлен на разработку моделей нейронных сетей для прогнозирования выброса радона с целью предсказания землетрясений. Радон является природным радиоактивным газом, концентрация которого может изменяться перед сейсмическими событиями, что делает его потенциальным предшественником землетрясений.

## Обзор проекта

Проект включает в себя:
- Сбор и обработку данных об уровне радона и сейсмической активности
- Разработку и обучение различных моделей нейронных сетей (LSTM, GRU, гибридные архитектуры)
- Оценку и сравнение производительности моделей
- Визуализацию результатов и прогнозов
- Контейнеризацию для воспроизводимого и масштабируемого развертывания


## Компоненты проекта

### Данные (`data/`)

Директория содержит наборы данных с измерениями уровня радона и сейсмической активности:
- Временные ряды концентрации радона
- Данные о сейсмических событиях
- Предобработанные наборы данных для обучения и тестирования

### Модели

Проект включает несколько типов директорий для моделей:
- `models_notepad/` - каталог для разработки и тестирования различных архитектур
- `model_save_preset/` - хранилище лучших моделей для использования в проекте
- `model_save_preset_old/` - архивное хранилище для исторического сравнения

### Инструменты метрик (`metric_standart/`)

Инструменты для стандартизированной оценки производительности моделей по различным метрикам, включая:
- RMSE (среднеквадратичная ошибка)
- MAE (средняя абсолютная ошибка)
- R² (коэффициент детерминации)
- И другие специализированные метрики

### Визуализация (`visualization/`)

Инструменты и дашборды для визуализации:
- Архитектуры моделей
- Истории обучения
- Сравнения производительности моделей
- Прогнозов и фактических значений

### Docker (`for_docker/`)

Файлы для контейнеризации проекта, обеспечивающие:
- Воспроизводимую среду выполнения
- Простое развертывание
- Масштабируемость

## Начало работы

### Требования

- Python 3.8-3.11 (рекомендуется Python 3.10)
- TensorFlow 2.x
- Keras
- NumPy, Pandas, Matplotlib, Seaborn
- Scikit-learn
- Streamlit (для визуализации)
- Docker (опционально, для контейнеризации)

### Установка

1. Клонирование репозитория:
   ```bash
   git clone <репозиторий-проекта>
   cd Project-E
   ```

2. Установка зависимостей:
   ```bash
   pip install -r requirements.txt
   ```

3. Запуск визуализатора:
   ```bash
   cd visualization
   streamlit run dashboard.py
   ```

## Обучение моделей

Для обучения новых моделей используйте Jupyter ноутбук `testing_models.ipynb`:

```bash
jupyter notebook testing_models.ipynb
```

## Оценка моделей

Для оценки производительности моделей используйте инструменты из директории `metric_standart`:

```bash
python metric_standart/run_evaluation.py --data data/data.csv --models-dir model_save_preset/models
```
