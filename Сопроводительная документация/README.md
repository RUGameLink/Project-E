# Сопроводительная документация проекта

Эта директория содержит документацию к проекту по разработке моделей нейронных сетей для прогнозирования выброса радона с целью предсказания землетрясений.

## Содержимое директории

```
Сопроводительная документация/
├── Статья Вовиков_Д_Е.docx           # Научная статья с описанием методологии и результатов
├── Титул + задание.docx              # Титульный лист и техническое задание
├── 29.05.2024 Вовиков Д. Курсовая.docx # Курсовая работа с полным описанием проекта
├── old/                              # Архивные версии документации
└── README.md                         # Этот файл
```

## Описание документов

### Научная статья

Файл "**Статья Вовиков_Д_Е.docx**" содержит научную статью с детальным описанием:
- Теоретической базы исследования
- Методологии прогнозирования выброса радона
- Архитектуры используемых нейронных сетей
- Результатов экспериментов и их анализа
- Выводов и направлений дальнейших исследований

### Техническое задание

Файл "**Титул + задание.docx**" включает:
- Титульный лист проекта
- Формальное техническое задание на разработку
- Спецификацию требований к моделям
- Критерии оценки результатов работы
- График выполнения проекта

### Курсовая работа

Файл "**29.05.2024 Вовиков Д. Курсовая.docx**" представляет собой полное описание проекта в формате курсовой работы:
- Обзор литературы по теме исследования
- Теоретическое обоснование выбранного подхода
- Подробное описание архитектуры моделей
- Методологию проведения экспериментов
- Результаты тестирования и анализ производительности
- Выводы и практические рекомендации
- Список использованных источников

### Архивные документы

Директория "**old/**" содержит архивные версии документации, сохраненные для исторической справки и отслеживания эволюции проекта.

## Использование документации

Документация предназначена для:
1. Ознакомления с теоретическими основами проекта
2. Понимания методологии разработки и обучения моделей
3. Анализа результатов экспериментов и выводов исследования
4. Планирования дальнейших направлений развития проекта

## Актуализация документации

При внесении существенных изменений в проект рекомендуется обновлять соответствующие разделы документации для поддержания ее актуальности.
