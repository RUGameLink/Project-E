# Модуль оценки моделей нейронных сетей

Этот модуль предназначен для оценки моделей нейронных сетей формата h5 (Keras/TensorFlow) с использованием метрик, применяемых в модуле визуализации. Модуль позволяет загружать модели, оценивать их на тестовых данных и сохранять результаты в структурированном виде.

## Особенности

- Загрузка моделей в формате .h5
- Оценка моделей с использованием стандартных метрик регрессии (RMSE, MAE, MSE и др.)
- Сохранение результатов в формате, совместимом с модулем визуализации
- Управление группами моделей и их метриками
- Веб-интерфейс для удобного взаимодействия

## Установка

1. Убедитесь, что установлен Python 3.8 или новее
2. Запустите `install_evaluator.bat` для создания виртуального окружения и установки зависимостей
3. После установки запустите `run_evaluator.bat` для запуска сервера

## Использование

1. Запустите сервер выполнив `run_evaluator.bat`
2. Откройте веб-браузер и перейдите по адресу http://localhost:8000/
3. Загрузите модель в формате .h5 и тестовые данные в формате .csv
4. Укажите группу и опционально имя модели
5. Нажмите "Оценить модель"
6. После оценки модели и её результаты будут сохранены в структуре каталогов model_save_preset

## Конфигурация

Настройки приложения хранятся в файле `config.ini`:

```ini
[Paths]
models_directory = ../model_save_preset

[Data]
test_data_path = test_data.csv

[Logging]
log_level = INFO
```

## Метрики оценки моделей

Модуль использует следующие метрики для оценки моделей:

- RMSE (Root Mean Squared Error) - корень из среднеквадратичной ошибки
- MSE (Mean Squared Error) - среднеквадратичная ошибка
- MAE (Mean Absolute Error) - средняя абсолютная ошибка
- Максимальная ошибка (Max Error)
- Объяснённая дисперсия (Explained Variance)

## Совместимость с модулем визуализации

Модуль оценки сохраняет результаты в формате, совместимом с модулем визуализации. Оцененные модели и их метрики становятся доступны для отображения и анализа в модуле визуализации.
