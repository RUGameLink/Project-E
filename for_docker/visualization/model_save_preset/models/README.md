# Хранилище моделей для визуализации в Docker

Эта директория содержит сохраненные модели нейронных сетей, используемые для визуализации в Docker-среде проекта прогнозирования выброса радона с целью предсказания землетрясений.

## Структура директории

```
models/
├── 1 old/             # Базовые модели первого поколения
├── 2 new/             # Улучшенные модели второго поколения
├── 3 alt_model/       # Альтернативные архитектуры моделей
├── 4 alt_new_model/   # Улучшенные альтернативные модели
├── 5_test/            # Тестовые экспериментальные модели
└── README.md          # Этот файл
```

## Назначение директории

Данная директория предназначена для хранения моделей, которые будут использоваться модулем визуализации в Docker-контейнере для:

1. **Интерактивной визуализации**:
   - Сравнения прогнозов различных моделей
   - Визуального анализа архитектуры моделей
   - Демонстрации работы моделей на тестовых данных

2. **Генерации отчетов**:
   - Создания визуальных отчетов о производительности моделей
   - Формирования графиков и диаграмм для презентаций
   - Построения сравнительных таблиц различных моделей

## Особенности моделей для визуализации

Модели в этой директории имеют следующие особенности:

- Сохранены с дополнительными метаданными для визуализации внутренней структуры
- Включают информацию о весах для визуализации активаций нейронов
- Содержат предварительно вычисленные прогнозы для эталонных наборов данных

## Использование в системе визуализации

```python
import tensorflow as tf
import visualization.visualizer as vis

# Загрузка модели для визуализации
model_path = "/app/visualization/model_save_preset/models/2 new/hybrid_model_v2.h5"
model = tf.keras.models.load_model(model_path)

# Создание визуализатора
visualizer = vis.ModelVisualizer(model)

# Визуализация архитектуры модели
visualizer.plot_architecture(save_path="/app/output/model_architecture.png")

# Визуализация прогнозов модели
test_data = visualizer.load_test_data()
visualizer.plot_predictions(test_data, save_path="/app/output/model_predictions.png")

# Визуализация активаций нейронов
visualizer.plot_activation_maps(test_data[0:1], layer_names=["lstm_1", "lstm_2"],
                               save_path="/app/output/activation_maps.png")
```

## Взаимодействие с веб-интерфейсом

Модели из этой директории используются веб-интерфейсом визуализации Docker-приложения для:

1. Отображения списка доступных моделей
2. Выбора моделей для сравнения
3. Генерации интерактивных графиков и диаграмм
4. Создания пользовательских отчетов

## Добавление новых моделей

Для добавления новых моделей в систему визуализации:

1. Сохраните модель в соответствующей поддиректории (в зависимости от типа модели)
2. Убедитесь, что модель сохранена с правильными метаданными для визуализации
3. При необходимости обновите индексный файл моделей для обновления списка в интерфейсе
