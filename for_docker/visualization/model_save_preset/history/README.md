# История обучения моделей для визуализации в Docker

Эта директория содержит файлы истории обучения моделей нейронных сетей, используемые для визуализации процесса обучения в Docker-среде проекта прогнозирования выброса радона.

## Структура директории

```
history/
├── 1 old/             # История обучения базовых моделей
├── 2 new/             # История обучения улучшенных моделей
├── 3 alt_model/       # История обучения альтернативных моделей
├── 4 alt_new_model/   # История обучения улучшенных альтернативных моделей
├── 5_test/            # История обучения тестовых моделей
└── README.md          # Этот файл
```

## Назначение директории

Данная директория содержит историю обучения моделей в форматах `.pkl` и `.json`, которая используется системой визуализации в Docker-контейнере для:

1. **Визуализации процесса обучения**:
   - Построения графиков изменения функции потерь и метрик
   - Анализа скорости сходимости различных моделей
   - Выявления проблем переобучения или недообучения

2. **Сравнительного анализа**:
   - Сопоставления эффективности различных архитектур
   - Оценки влияния гиперпараметров на процесс обучения
   - Определения оптимального количества эпох обучения

## Форматы и содержимое файлов

Файлы истории хранятся в следующих форматах:
- `.pkl` - сериализованные Python-объекты для быстрого доступа
- `.json` - текстовый формат для просмотра и редактирования

Каждый файл истории содержит:
- Значения функций потерь на каждой эпохе
- Значения метрик (accuracy, MAE, MSE и др.)
- Параметры обучения (learning rate, batch size)
- Временные метки для анализа производительности

## Использование в системе визуализации

```python
import pickle
import json
import matplotlib.pyplot as plt
from visualization.history_visualizer import HistoryVisualizer

# Загрузка истории обучения
history_path = "/app/visualization/model_save_preset/history/2 new/hybrid_model_v2.pkl"
with open(history_path, "rb") as f:
    history = pickle.load(f)

# Создание визуализатора истории
visualizer = HistoryVisualizer(history)

# Визуализация динамики функции потерь
visualizer.plot_loss(save_path="/app/output/loss_curve.png")

# Визуализация динамики метрик
visualizer.plot_metrics(metrics=["mae", "mse", "r2"], 
                       save_path="/app/output/metrics_curve.png")

# Создание сводного отчета
visualizer.generate_training_report(save_path="/app/output/training_report.html")
```

## Интеграция с веб-интерфейсом

Файлы истории обучения используются веб-интерфейсом визуализации для:

1. Отображения динамики обучения выбранных моделей
2. Создания интерактивных графиков с возможностью масштабирования
3. Сравнения нескольких моделей на одном графике
4. Формирования таблиц с ключевыми метриками по эпохам

## Добавление новой истории обучения

Для добавления новых файлов истории обучения:

1. Сохраните файл истории в соответствующей поддиректории
2. Убедитесь, что формат файла соответствует ожидаемому интерфейсом визуализации
3. При необходимости обновите индексный файл для отображения новой истории в списке

- Статистический анализ скорости сходимости моделей
