# Визуализатор моделей нейронных сетей

Этот инструмент предназначен для визуализации и сравнения моделей нейронных сетей, их архитектуры, метрик производительности и истории обучения.

## Требования

- Windows 10/11
- Python 3.8-3.11 (рекомендуется Python 3.10)
- 500 МБ свободного места на диске
- Подключение к интернету для установки зависимостей

## Установка

1. **Автоматическая установка (рекомендуется)**:
   - Запустите скрипт `install_visualization.bat` из каталога `visualization`
   - Следуйте инструкциям на экране

2. **Ручная установка**:
   ```bash
   # Создание виртуального окружения
   python -m venv venv
   
   # Активация виртуального окружения
   venv\Scripts\activate
   
   # Установка зависимостей
   pip install -r requirements.txt
   ```

## Запуск визуализатора

1. **Автоматический запуск**:
   - Запустите скрипт `run_dashboard.bat` из каталога `visualization`

2. **Ручной запуск**:
   ```bash
   venv\Scripts\activate
   streamlit run dashboard.py
   ```

## Конфигурация

Визуализатор может быть настроен через файл `config.ini`, который содержит пути к директориям моделей и другие настройки.

1. **Автоматическая настройка**:
   - Запустите скрипт `setup_config.bat` из каталога `visualization`
   - Следуйте инструкциям на экране

2. **Ручная настройка**:
   - Отредактируйте файл `visualization/config.ini` в текстовом редакторе

3. **Структура config.ini**:
   ```ini
   [Paths]
   models_directory = ../model_save_preset  # Путь к директории с моделями
   
   [Logging]
   log_level = INFO  # Уровень логирования (DEBUG, INFO, WARNING, ERROR, CRITICAL)
   ```

4. **Настройка через командную строку**:
   ```bash
   python setup_config.py --models-dir "путь/к/моделям" --log-level INFO
   ```

5. **Смена пути через интерфейс**:
   - В дашборде перейдите в раздел "Диагностика" в боковой панели
   - Раскройте "Настройки путей" и введите новый путь
   - Нажмите "Сохранить путь" и перезагрузите страницу

## Структура каталогов

- `visualization/` - основной каталог визуализатора
  - `dashboard.py` - основной файл дашборда Streamlit
  - `model_comparison_utils.py` - утилиты для сравнения моделей
  - `model_architecture.py` - утилиты для визуализации архитектуры моделей
  - `model_visualizer.py` - дополнительные инструменты визуализации
  - `config.ini` - файл конфигурации для путей и настроек
  - `setup_config.py` - скрипт для настройки конфигурации
  - `setup_config.bat` - запуск настройки конфигурации в Windows
  - `requirements.txt` - зависимости Python
  - `run_dashboard.bat` - скрипт для запуска дашборда
  - `install_visualization.bat` - скрипт для установки

- `model_save_preset/` - каталог с сохраненными моделями и историей
  - `models/` - сохраненные модели в формате .h5
    - `1 old/` - модели группы 1
    - `2 new/` - модели группы 2
    - `3 alt_model/` - модели группы 3
    - `4 alt_new_model/` - модели группы 4
  - `history/` - история обучения моделей
    - `1 old/` - история моделей группы 1
    - `2 new/` - история моделей группы 2
    - `3 alt_model/` - история моделей группы 3
    - `4 alt_new_model/` - история моделей группы 4

## Функциональность дашборда

1. **Обзор моделей**
   - Просмотр всех моделей по группам
   - Сравнение основных метрик производительности

2. **История обучения**
   - Визуализация процесса обучения моделей
   - Сравнение метрик обучения разных моделей

3. **Сравнение моделей**
   - Детальное сравнение нескольких моделей
   - Радарные диаграммы для визуального сравнения

4. **Лучшие модели**
   - Выбор лучших моделей по выбранным метрикам
   - Детальная информация о лучших моделях

5. **Визуализация архитектуры**
   - Отображение слоев и структуры модели
   - Информация о параметрах модели

## Устранение неполадок

1. **Проблемы с TensorFlow**
   - TensorFlow 2.16+ поддерживает только Python 3.10-3.11
   - Используйте Python 3.10 для оптимальной совместимости

2. **Ошибки при чтении моделей**
   - Убедитесь, что модели доступны в каталоге `model_save_preset/models`
   - Проверьте соответствие форматов файлов (.h5)

3. **Ошибки при загрузке истории**
   - История должна быть в формате JSON или PKL
   - Проверьте структуру файлов истории

4. **Сброс настроек**
   - Удалите каталог `venv` и запустите установку заново
   - Запустите скрипт `remove_all.bat` для полной очистки
