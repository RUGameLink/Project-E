# Визуализатор моделей нейронных сетей для Docker

Этот инструмент предназначен для визуализации и сравнения моделей нейронных сетей в Docker-контейнере, позволяя анализировать архитектуру моделей, метрики производительности и историю обучения в изолированной среде.

## Особенности Docker-версии

- Оптимизирована для работы в контейнере Docker
- Настроена для доступа к моделям через смонтированные тома
- Совместима с любой ОС, поддерживающей Docker (Windows, Linux, macOS)
- Предконфигурирована для работы без дополнительной настройки

## Запуск в Docker

1. **Запуск через docker-compose**:
   ```bash
   # В корневой директории проекта
   docker-compose up -d
   ```

2. **Ручной запуск**:
   ```bash
   # Сборка образа
   docker build -t radon-model-viz:latest .
   
   # Запуск контейнера
   docker run -p 8501:8501 -v ./model_save_preset:/app/model_save_preset radon-model-viz:latest
   ```

3. **Доступ к интерфейсу**:
   - Откройте браузер и перейдите по адресу http://localhost:8501

## Конфигурация

Визуализатор в Docker-контейнере использует предустановленную конфигурацию, но может быть настроен с помощью переменных окружения:

```yaml
environment:
  - MODEL_DIR=/app/model_save_preset/models
  - LOG_LEVEL=INFO
```

## Структура данных

Данные внутри контейнера организованы следующим образом:

- `/app/visualization/` - файлы визуализатора
- `/app/model_save_preset/` - смонтированный том с моделями и историей

## Функциональность дашборда

1. **Обзор моделей**
   - Просмотр всех моделей по группам
   - Сравнение основных метрик производительности

2. **История обучения**
   - Визуализация процесса обучения моделей
   - Сравнение метрик обучения разных моделей

3. **Сравнение моделей**
   - Детальное сравнение нескольких моделей
   - Радарные диаграммы для визуального сравнения

4. **Лучшие модели**
   - Выбор лучших моделей по выбранным метрикам
   - Детальная информация о лучших моделях

5. **Визуализация архитектуры**
   - Отображение слоев и структуры модели
   - Информация о параметрах модели

## Устранение неполадок в Docker

1. **Проблемы с доступом к порту**
   - Убедитесь, что порт 8501 не занят другим приложением
   - Проверьте правила брандмауэра

2. **Проблемы с монтированием томов**
   - Убедитесь, что путь к директории model_save_preset указан корректно
   - Проверьте права доступа к файлам

3. **Ошибки контейнера**
   - Проверьте логи контейнера: `docker logs <container_id>`
   - Перезапустите контейнер: `docker-compose restart`

4. **Обновление образа**
   - Для обновления образа выполните: `docker-compose build --no-cache`
   - Затем перезапустите: `docker-compose up -d`
