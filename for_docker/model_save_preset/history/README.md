# История обучения моделей для Docker-среды

Эта директория содержит сохраненную историю обучения моделей нейронных сетей, используемых в Docker-версии проекта для прогнозирования выброса радона с целью предсказания землетрясений.

## Структура директории

```
history/
├── 1 clean model/        # История обучения базовых моделей
├── 2 hybrid model/       # История обучения гибридных моделей
├── 3 experimental model/ # История обучения экспериментальных моделей
├── 4 orcestration model/ # История обучения оркестрированных моделей
└── README.md             # Этот файл
```

## Особенности файлов истории для Docker-среды

Файлы истории в этой директории имеют следующие особенности:

1. **Форматы данных**:
   - `.pkl` - бинарный формат (Python pickle) для эффективного хранения и быстрой загрузки
   - `.json` - текстовый формат для совместимости и удобства просмотра

2. **Оптимизация для Docker**:
   - Сжатые версии файлов для уменьшения размера образа
   - Упрощенные структуры данных для экономии памяти

## Содержимое файлов истории

Каждый файл истории содержит подробную информацию о процессе обучения соответствующей модели:

- Значения функции потерь (loss) по эпохам
- Значения метрик (MAE, MSE, R² и др.) на обучающей выборке
- Значения метрик на валидационной выборке
- Параметры обучения (learning rate, batch size и др.)
- Информация о времени обучения каждой эпохи

## Использование в Docker-контейнере

### Загрузка и анализ истории обучения

```python
import pickle
import json
import os
import matplotlib.pyplot as plt

# Путь к файлу истории в контейнере
history_path = "/app/model_save_preset/history/2 hybrid model/hybrid_model_v2.pkl"

# Загрузка истории обучения из .pkl файла
def load_training_history(filepath):
    if os.path.exists(filepath):
        with open(filepath, "rb") as f:
            return pickle.load(f)
    else:
        print(f"Ошибка: файл истории не найден по пути {filepath}")
        return None

# Загрузка и визуализация
history = load_training_history(history_path)
if history:
    # Визуализация изменения функции потерь
    plt.figure(figsize=(10, 6))
    plt.plot(history['loss'], label='Обучающая выборка')
    plt.plot(history['val_loss'], label='Валидационная выборка')
    plt.title('Динамика функции потерь')
    plt.xlabel('Эпоха')
    plt.ylabel('Значение потерь')
    plt.legend()
    plt.grid(True)
    
    # Сохранение графика
    plt.savefig('/app/output/loss_history.png')
    print("График сохранен в /app/output/loss_history.png")
```

## Использование истории для мониторинга и анализа

В контейнере файлы истории используются для:

1. **Мониторинга качества моделей**:
   - Отслеживание стабильности моделей на разных наборах данных
   - Сравнение производительности различных архитектур

2. **Отчетности**:
   - Генерация автоматических отчетов о качестве моделей
   - Создание графиков для визуализации динамики обучения

3. **Принятия решений**:
   - Определение необходимости дообучения моделей
   - Выявление проблем переобучения или недообучения

## Обновление файлов истории

Аналогично моделям, файлы истории можно обновлять через монтирование томов или создание нового образа с обновленными данными.
