# Модели нейронных сетей для Docker-среды

Эта директория содержит сохраненные модели нейронных сетей в формате `.h5` (Keras/TensorFlow), оптимизированные для использования в Docker-контейнере проекта прогнозирования выброса радона.

## Структура директории

```
models/
├── 1 clean model/        # Базовые модели с простой архитектурой
├── 2 hybrid model/       # Гибридные модели с улучшенной архитектурой
├── 3 experimental model/ # Экспериментальные модели с нестандартной архитектурой
├── 4 orcestration model/ # Оркестрированные ансамбли моделей
└── README.md             # Этот файл
```

## Особенности моделей для Docker-среды

Модели в этой директории специально оптимизированы для использования в контейнерной среде:

1. **Оптимизация размера и производительности**:
   - Конвертированы в оптимальный формат для быстрой загрузки
   - Удалены ненужные промежуточные данные и метаданные
   - Применена квантизация весов, где это возможно

2. **Независимость от версий библиотек**:
   - Модели сохранены в формате, обеспечивающем совместимость с TensorFlow в контейнере
   - Включена минимальная информация о среде для упрощения загрузки

## Группы моделей

### 1. Базовые модели (clean model)

Простые модели для базовых сценариев прогнозирования:
- Классические архитектуры LSTM и GRU
- Упрощенная структура слоев
- Быстрое время инференса

### 2. Гибридные модели (hybrid model)

Продвинутые гибридные архитектуры:
- Комбинированные LSTM/GRU слои
- Механизмы внимания
- Улучшенная предобработка данных

### 3. Экспериментальные модели (experimental model)

Исследовательские архитектуры с новыми подходами:
- Модели с нестандартной структурой
- Обработка данных в частотной области
- Экспериментальные механизмы отбора признаков

### 4. Оркестрированные модели (orcestration model)

Ансамбли моделей для повышения точности прогнозирования:
- Комбинации различных типов моделей
- Взвешенное усреднение результатов
- Каскадная структура прогнозирования

## Обновление моделей

При необходимости обновления моделей в контейнере:

1. **Монтирование как тома**:
   ```bash
   docker run -v /local/path/to/models:/app/model_save_preset/models ...
   ```

2. **Создание нового образа**:
   ```dockerfile
   FROM project-e-base
   COPY ./new_models /app/model_save_preset/models
   ```
